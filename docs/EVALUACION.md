# Evaluación por fases

F0: autenticación, RBAC, CSRF, cookies, tokens caducados/reutilizados, revocación de sesiones,
contratos ORCID, SMTP y flujo de navegador desktop/móvil. Cobertura backend mínima 70 %.
Ver `VALIDACION_F0.md` para resultados observados y límites.

F1: tres revisiones OA reales con secciones, referencias y tablas legibles.
F2: al menos 90 % de citas verificadas contra textos reales.
F4–F6: gold standard retrospectivo aprobado por investigadores; precisión, recall, F1,
WSS@95, matriz de confusión, exactitud de campos/celdas y recall de búsqueda.
F8–F9: rendimiento, accesibilidad y SUS con 5–10 investigadores (objetivo >=70).

No se atribuyen valores a métricas científicas ni de usabilidad sin ejecutar su evaluación.
No se fabrican conjuntos etiquetados para aparentar el cumplimiento de las metas.
